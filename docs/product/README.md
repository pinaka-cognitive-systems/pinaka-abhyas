# Product

Product documents. They say what the product is, for whom, and what it will not
do. They name roles, never people.

- `boundary.md`: the student, the job, the non-goals, the principles, and the
  decision rule. Every other document cites it.
- `objects.md`: the object model and the glossary. One word per thing, with the
  name the code uses.

The PRD and the TRD come next and hang from these two pages.

A change to a non-goal, a principle, the exam list, or the decision rule in
`boundary.md` needs an ADR in `docs/adr/`.
