# ARCHIVED: Python engine prototype

This directory is the historical Python prototype of the Pinaka Abhyas engine. It is
superseded by the TypeScript engine per docs/adr/0010-single-typescript-engine.md.

The prototype is kept as a reference for its design intent, honesty gates, tier
structure, and EV model. Its tests no longer run in CI. The live Python cross-check
of the engine math is in crosscheck/.

Do not edit this directory. Do not add it to CI. Treat it as read-only historical
record.
